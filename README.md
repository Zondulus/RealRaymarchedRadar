Introduction

RealRaymarchedRadar is exactly what it sounds like: a simulated radar which uses raymarching to sample the density of clouds along its beam. This provides an actual live weather radar for Kerbal Space Program! It is just a weather radar at this time and is not intended to detect terrain or other vehicles. It is in an alpha state and I am still working on reducing the number of artifacts and testing its performance over long periods.



RealRaymarchedRadar is a standalone mod but also a companion for VolumetricAwareWeather. The radar is extensively configurable and is currently tuned to correspond to visual clouds coverage and areas where turbulence from Volumetric Aware Weather begins. This mod is compatible with free Volumetric Clouds V3 (download here) and V5 as well as add-on mods such as Space Potato's Visual Enhancements.



The radar has these features:





Switchable Short/Long range modes, ranges are 10 and 20 km by default but can be changed by config file





Short range is fast and has a vertical sweep angle of +/- 10 degrees (all configurable)



Long range is slow and has a vertical sweep angle of +/- 5 degrees



Switchable Global/Forward sweep modes, sweep speed adjustable by config file



Tunable thresholds for coverage, coloration, and resolution via config file



Abysmal placeholder toolbar button by yours truly (will be improved for real release)



It is performant and robust across long playtimes and physical timewarps. There are noticeable artifacts or occasional glitches with the returns which I am working on reducing, but they do not make it unusable or unreliable.

Installation

Requires EVE Redux and any volumetric clouds config. Remove old versions prior to updating. Extract and merge GameData with your existing folder.
